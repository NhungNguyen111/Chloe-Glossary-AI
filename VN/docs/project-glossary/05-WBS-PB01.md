## Rolling wave

- **Wave 1 — Foundation:** 1.0–2.0, chốt scope và dữ liệu.
- **Wave 2 — Core slice:** 3.0–5.0, build đường đi tìm → xem → ôn.
- **Wave 3 — Operate:** 6.0–8.0, I/O, dashboard, test và telemetry.
